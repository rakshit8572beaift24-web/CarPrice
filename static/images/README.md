# Car Images

This folder is for car images. The application currently uses Font Awesome icons for car displays, but you can add actual car images here if desired.

To add car images:
1. Place car images in this folder
2. Update the HTML/CSS to reference these images
3. Use appropriate naming conventions (e.g., maruti_swift.jpg, hyundai_i20.jpg)

The application works perfectly without actual images using the current icon-based design.
